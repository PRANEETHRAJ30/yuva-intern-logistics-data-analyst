# Yuva Intern - Logistics Data Analyst - Week 1

## Project
**Strategic Planning and Data Exploration in Logistics**

## Scenario
This project proposes an e-commerce logistics analytics workflow focused on delivery performance, delay reduction, route efficiency, and resource allocation.

## Week 1 Deliverables
- Strategic planning report: `YuvaIntern_Logistics_Data_Analyst_Week1_Report.docx`
- Python illustration: `logistics_week1_analysis.py`

## KPIs
1. On-Time Delivery Rate
2. Average Delivery Delay
3. Average Delivery Time
4. Logistics Cost per Order
5. Capacity / Vehicle Utilization

## Analytical Methods
- Descriptive statistics and EDA
- Linear regression for delivery-delay prediction
- K-Means clustering for logistics segmentation
- Vehicle routing / route optimization using Google OR-Tools as a future extension

## Public Dataset
DataCo Smart Supply Chain dataset on Kaggle:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

## How to Run
1. Download `DataCoSupplyChainDataset.csv` from the public dataset source.
2. Place the CSV in the same folder as `logistics_week1_analysis.py`.
3. Install dependencies:
   `pip install pandas numpy matplotlib scikit-learn`
4. Run:
   `python logistics_week1_analysis.py`

## Note
The Week 1 report distinguishes between proposed methodology and measured results. The illustrative figures inside the report are conceptual and are not claimed as results from the dataset.
