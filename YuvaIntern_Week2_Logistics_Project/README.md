# Yuva Intern - Logistics Data Analyst - Week 2

## Topic
Data Collection, Cleaning, and Preprocessing for Logistics Analysis.

## Contents
- `YuvaIntern_Logistics_Data_Analyst_Week2_Report.docx` - final Week 2 report
- `logistics_week2_preprocessing.py` - reusable Python preprocessing template

## Reference dataset
DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS
Mendeley Data: https://data.mendeley.com/datasets/8gx2fvg2k6/5

## Main preprocessing steps
1. Load and inspect the dataset
2. Profile missing values and duplicates
3. Handle missing values according to field meaning
4. Detect possible outliers using the IQR rule
5. Standardize date, numeric, and categorical fields
6. Validate the cleaned dataset

The Week 2 report uses simulated examples where explicitly stated and does not invent unsupported numeric results for the public dataset.
