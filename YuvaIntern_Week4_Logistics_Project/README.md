# Yuva Intern - Logistics Data Analyst - Week 4

## Topic
Predictive Modeling and Optimization in Logistics Systems.

## Contents
- `YuvaIntern_Logistics_Data_Analyst_Week4_Report.docx` - final report
- `hypothetical_logistics_week4_dataset.csv` - simulated dataset used for the analysis
- `logistics_week4_predictive_optimization.py` - reproducible Python workflow
- PNG files - model and optimization visualizations
- `requirements.txt` - Python dependencies

## Project Summary
This project predicts delivery time using Linear Regression and Random Forest, evaluates the models with MAE, RMSE, R-squared, cross-validation, and hyperparameter tuning, and demonstrates a small vehicle-allocation optimization problem using linear programming.

## Important Note
The dataset and results are simulated for the Week 4 internship task. They are intended to demonstrate the analytical method and should not be interpreted as real company performance.

## Run
1. Install dependencies with `pip install -r requirements.txt`
2. Run `python logistics_week4_predictive_optimization.py`
